# Background music tracks

Preset tracks referenced by `MUSIC_TRACKS` in `src/lib/invitation/sections.ts`.

- `flora-theme.mp3` — NOT COMMITTED YET. Drop a royalty-free instrumental here
  (e.g. from Pixabay Music / Free Music Archive, CC0 or similarly licensed).
  Until the file exists, the invitation's audio toggle hides itself
  automatically (the `<audio>` element fires `onError`), so the page works
  without it.

Keep files small (< 3 MB, 128 kbps mp3 is plenty for background music).
