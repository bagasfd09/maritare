# Folk Garden — watercolor floral assets

User-provided transparent watercolor/botanical PNGs (their own assets), optimized
to webp here. Palette: burgundy/maroon, orange, pink/pastel, white, green, gold.
Used by the Folk Garden invitation template sections (src/components/invitation/folk).

## Bouquets / clusters (multi-flower)
- `burgundy-roses-bouquet.webp` — maroon roses + peony + gold leaves (lush, hero cluster)
- `babys-breath-bouquet.webp` — white baby's breath, cream ribbon
- `hibiscus-peony-arrangement.webp` — horizontal: red hibiscus + peony + greenery
- `peony-alstroemeria-bouquet.webp` — white peony + red alstroemeria (horizontal)
- `pastel-chrysanthemum-bouquet.webp` — pastel pink mums + green hydrangea
- `flowers-on-rock.webp` — tulip/alstroemeria growing on a rock

## Single flowers
- `bee-balm-red.webp`, `lily-red.webp`, `calendula-orange.webp`,
  `trumpet-vine-orange.webp`, `peony-pink.webp`, `calla-lily-white.webp`,
  `white-umbel-cluster.webp`

## Foliage
- `grass-border.webp` — wide green grass strip (bottom borders)
- `green-leaves-branch.webp` — leafy branch (no flowers)

## Ornament / scene
- `gold-ornament.webp` — hanging gold Javanese-style ornament (tall, dividers/accents)
- `tree-green-01.webp` — lush green tree
- `landscape-watercolor.webp` — faded watercolor landscape (soft full-bleed background)

All transparent except `landscape-watercolor`. Render via plain `<img loading="lazy">`.
